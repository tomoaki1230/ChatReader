# ChatReader

Google Chat に届いた新しいメッセージを、音声で読み上げる Chrome 拡張機能です。
画面を見ていなくても、誰からどんなメッセージが来たかを耳で知ることができます。

> 例: 「営業チーム、佐藤、明日の件です」

---

## できること

- **新着メッセージの読み上げ** … 「スペース名、送信者名、本文」の順に読み上げます。
- **開いていないスペースの新着も** … 別のスペースや DM に届いたメッセージも知らせます（くわしくは「[開いていないスペースの新着について](#開いていないスペースの新着について)」）。
- **声の調整** … 声の種類・音量・速度・高さを変えられます。
- **読み方の調整** … スペース名や送信者名を読むか、名前に「さん」を付けるか、@メンションを読むかなどを選べます。
- **自分のメッセージは読まない** … 自分が送ったメッセージは読み上げません（設定で読むこともできます）。
- **外部に送信しない** … パソコンに入っている音声だけを使います。メッセージの内容をインターネット上の音声サービスに送ることはありません。

---

## 動作環境

| 項目 | 内容 |
|---|---|
| ブラウザ | Google Chrome（バージョン 111 以降） |
| 対象 | ブラウザで開いた Google Chat（https://chat.google.com） |
| 音声 | パソコンに日本語の音声が入っていること（Windows・Mac には通常入っています） |

**対象外のもの:** Gmail の中の Chat 画面（mail.google.com）、スマートフォン、Google Chat のアプリ版では動きません。

## インストール

ChatReader は Chrome ウェブストアには公開していないため、次の手順で手動で追加します。

1. [リリースページ](../../releases) から `ChatReader-<バージョン>.zip` をダウンロードし、展開（解凍）します。
   展開したフォルダは、拡張機能を使っている間は**削除・移動しないでください**。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
3. 右上の「**デベロッパー モード**」を ON にします。
4. 「**パッケージ化されていない拡張機能を読み込む**」を押し、手順 1 で展開したフォルダ（`manifest.json` が入っているフォルダ）を選びます。
5. Google Chat（https://chat.google.com）を開きます。すでに開いている場合は**ページを再読み込み**してください。

ツールバーのパズルのアイコンから ChatReader を固定（ピン留め）しておくと、設定画面をすぐ開けて便利です。

## はじめに設定しておくこと

### 声を確かめる
ツールバーの ChatReader アイコンを押すと設定画面が開きます。「**試聴**」を押して、声が聞こえるか確かめてください。
聞こえない場合は「[困ったとき](#困ったとき)」をご覧ください。

### Google Chat の通知を許可する（おすすめ）
開いていないスペースのメッセージを**本文まで**読み上げるには、Google Chat のデスクトップ通知が必要です。

1. Google Chat を開き、アドレスバー左のアイコンから「サイトの設定」を開いて、「通知」を「**許可**」にします。
2. Google Chat の右上の歯車（設定）から、通知を ON にします。
3. 特定のスペースのメッセージをすべて読ませたい場合は、そのスペースの通知設定を「**すべて**」にします（「@メンションのみ」だと、それ以外のメッセージは通知されません）。

通知を許可しなくても、開いているスペースのメッセージは読み上げます。開いていないスペースはスペース名だけを知らせます。

## 設定画面

| 欄 | 主な設定 |
|---|---|
| 読み上げ（右上のスイッチ） | 読み上げ全体の ON/OFF |
| 音声 | 声の種類、音量、速度、高さ、試聴 |
| 読み方 | スペース名を読む、送信者名を読む、名前に「さん」を付ける、最大文字数（長いメッセージは途中で「以下省略」） |
| 読み上げるメッセージ | 開いていないスペースの新着、スペースの更新情報（招待・参加など）、Chat を表示している時も読む、自分のメッセージも読む、自分の表示名 |
| メンション（@名前） | @名前 を読まない、「@全員」は「全員宛て」と伝える |
| 診断 | 動作状況や記録の確認（困ったときに使います） |

設定は変更するとすぐに反映されます。

### 開いていないスペースの新着について
「開いていないスペースの新着」で、次の 3 つから選べます。

| 選択肢 | 動き |
|---|---|
| 本文まで読む（通知が出る時）※初期設定 | Chat の通知が出たときは本文まで読み、出ないときは「○○ に新着メッセージ」とスペース名だけ知らせます |
| スペース名だけ知らせる | 本文は読まず、「○○ に新着メッセージ」とだけ知らせます（周りに人がいる場所などに） |
| 読まない | 開いているスペースのメッセージだけを読みます |

---

## 読み上げないもの・注意点

- **ページを開いたときやスペースを切り替えたとき**に表示される、すでにあるメッセージは読みません。
- **Chat のタブを閉じている間**に届いたメッセージは読めません。Chat のタブは開いたままにしてください（最小化や別のタブを見ていても大丈夫です）。
- **自分のアカウントから送ったメッセージ**（スマートフォンなど別の端末から送ったものを含む）は、開いていないスペースでは知らせられません。Google Chat が未読や通知にしないためです。
- 一度にたくさんの通知が届いたとき（スリープからの復帰など）は、数件だけ読んで、残りは「ほか N 件の新着があります」とまとめて知らせます。
- メンションの名前に空白が入る場合（例: @山田 太郎）、名前の一部が読まれることがあります。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 何も読み上げない | Google Chat のページを再読み込みしてください。右上の「読み上げ」スイッチが ON か確認してください。 |
| 拡張機能を更新したら読み上げなくなった | 更新後は、開いている Google Chat のページを**必ず再読み込み**してください。 |
| 「試聴」でも声が出ない | パソコンの音量を確認してください。声の一覧が空の場合は、パソコンに日本語の音声を追加してください（Windows:「設定」→「時刻と言語」→「音声」）。 |
| 別のスペースの本文が読まれない（スペース名だけになる） | 「[Google Chat の通知を許可する](#google-chat-の通知を許可するおすすめ)」の設定を確認してください。Chat の画面を見ている間は Chat が通知を出さないことが多く、その場合は本文を読めません。 |
| 突然読まなくなった | 設定画面の「診断」→「動作状況」で「セレクタを再学習」を押してください。Google Chat の画面が変わった場合でも、通常は自動で追従します。 |
| 不自然な読み方をする | 設定画面の「診断」→「診断ログ」の「コピー」で記録を取得し、開発者にお知らせください。 |

---

## プライバシー

- メッセージの内容を外部に送信しません。読み上げにはパソコン内の音声だけを使います。
- 動作に必要な権限は「読み上げ」と「設定の保存」の 2 つだけです。Google Chat 以外のページでは動きません。
- 診断ログ（メッセージの内容を含みます）はブラウザを閉じると消えます。パソコンに保存はしません。

---

## 更新・削除

- **更新:** 新しい ZIP を展開して前のフォルダと置き換え、`chrome://extensions` で ChatReader の再読み込みボタン（↻）を押し、Google Chat のページを再読み込みします。
- **削除:** `chrome://extensions` で ChatReader の「削除」を押します。

## 開発者向け

### 必要なもの
- Node.js 22.22.2 以降（24 系は 24.15.0 以降）

### フォルダ構成
| フォルダ | 内容 |
|---|---|
| `src/` | 拡張機能の本体（manifest.json、スクリプト、設定画面、アイコン） |
| `tests/` | 自動テスト（Node.js の標準テスト機能と jsdom） |
| `scripts/` | ビルドとアイコン作成のスクリプト |

### コマンド
```
npm install       # 初回のみ（テストに使う jsdom を入れます）
npm test          # テスト
npm run build     # dist/ChatReader/（読み込み用フォルダ）と dist/ChatReader-<バージョン>.zip を作成
npm run icons     # アイコンを作り直す（通常は不要）
```

### 開発中の動作確認
1. `npm run build` を実行します。
2. `chrome://extensions` で「パッケージ化されていない拡張機能を読み込む」から `dist/ChatReader` を選びます。
3. コードを変更したら、もう一度 `npm run build` を実行します。そのあと `chrome://extensions` で再読み込み（↻）し、Google Chat のページも再読み込みします。

リリース用の ZIP は `dist/ChatReader-<バージョン>.zip` です。
